# CTRL-060: the installed SDK checked outside the checkout, and a PC release manifest

The RT half of a release already existed: `tools/inspect/deployment.py --render` writes the RT package (units, hashes of
binaries/libraries/scripts, the arm_control commit it was built from) and its `install.py` applies and rolls back on the
box (`--apply`, rollback, `--check-host`; an operator step). This slice adds the two missing pieces.

* Library `tools/check/check_installed_sdk.py` (in the suite beside the other fake-server checks): builds this library's
  wheel from a scratch copy of the sources (no build isolation, no network, nothing written into the tree), installs it
  `--no-deps` into a scratch virtualenv that sees the base environment's site-packages but not this checkout, asserts
  `arm_control` is imported from the venv, and runs `check_sdk_supervisor.py` (a copy, from a scratch directory) with that
  interpreter: the SDK drives a supervisor (spawned from the checkout, as a deployment's full environment) and the C++
  fake RT server. The conda base environment has no `arm_control` installed, so only the wheel can satisfy the import.
* Project `tools/inspect/release.py` (`arm_control.release/v1`): the three commits, each required clean, reachable from
  origin and equal to the project's submodule pins; the wire versions (RT protocol 5, pose hold 6, reference 7, Cartesian 8,
  supervisor contract 1, stream 1); Python and the imported packages' versions; sha256 of every `configs/entries/real_*`
  RESOLVED config, the instance registry and the model bundles; with `--rt-package`, the rendered package's deployment.json
  hash and its source commit, which must equal the PC's arm_control. The capability list says software availability only:
  every hardware entry is `hardware_qualified: false`; the bench session owns qualification. Exit 1 when not publishable.
  Written under `$ARM_CONTROL_EXPORT_ROOT/<date>/release-<time>/` (CTRL-010), never into a repo. `--self-check` (project
  suite) covers dirty, off-origin, off-pin and a mismatched RT package.

Not done here (operator, at the bench): rendering and applying the RT package on the box, the host check transcript, the
release manifest of the set actually deployed.
